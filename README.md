# Echorouk Sunlight

Application Flutter de contrôle DMX pour les tournages d'Echorouk TV.

## Fonctionnement
- Envoie des messages OSC sur le réseau Wi-Fi au PC Sunlite (IP fixe: 192.168.1.50, port 7000)
- 8 sliders : Projo 1-4 (DMX 1-4) + Gobo 1-4 (DMX 5-8)

## Installation
Télécharger le `.ipa` ou `.apk` depuis l'onglet **Actions** de ce dépôt GitHub.

## Configuration réseau requise
- PC Sunlite : IP fixe `192.168.1.50`
- Port OSC : `7000`
- iPhone et PC sur le même réseau Wi-Fi
